# Dr. Wang Warren Chen — Personal Homepage

Static academic homepage prepared for GitHub Pages. The site is organized as separate HTML pages rather than one long scrolling page.

The original Flag Counter is active at the bottom of the Home page.

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/`.

## GitHub Pages

The recommended repository name is `WangWarrenChen.github.io`. Publishing is intentionally not performed until the owner has reviewed the local preview.
